## LumiCore 是什么

LumiCore 是一款以用户行为为导向、以语音和自然语言交互为主要入口的本地智能体产品。它可以：

- 使用云端模型、本地模型或自定义 OpenAI 兼容服务；
- 保存用户自己的会话、记忆、知识库、任务和人格配置；
- 根据任务选择技能、工具、MCP 服务、桌面程序或一个明确授权的外部 AI 工具；
- 在指挥中心持续沟通、拆解任务、记录进度并核验结果；
- 在个人域和组织域之间保持清晰的数据与权限边界；
- 通过行业定制版把通用能力收敛成更轻、更稳定的业务流程。

LumiCore 不把能力锁死在某一个模型上。模型负责理解和推理，技能与工具负责执行，任务账本与回执负责证明发生了什么。

## 工作方式

```text
语音 / 文字 / 组织消息
          ↓
统一意图识别与关系判断
          ↓
风险策略与外部操作确认
          ↓
模型编排 → 技能 / 工具 / MCP / 桌面 / 外部 AI
          ↓
工具回执、幂等校验与任务账本
          ↓
指挥中心状态、长期记忆与最终回复
```

### 统一意图与安全执行

- 区分读取、创建、修改、导航、解释、纠错和状态查询；
- 区分无副作用、本地写入和外部提交；
- 发送、发布、提交等外部操作在最终执行前确认目标与内容；
- 外部操作超时后先查询结果，不盲目重复发送；
- 用户纠错、追问和质问默认不会被误当成新的工具任务；
- 客户端导航、桌面控制与外部平台调用不会自动降级成不相关操作。

### 持久任务与真实回执

- 任务、子任务、阻塞原因、租约、幂等键和完成来源持久保存；
- 工具调用记录请求、目标、输入摘要、结果和验证状态；
- 状态查询可以关联当前轮、历史任务和迟到回执；
- 最终回复以持久回执为事实来源，模型叙述不能覆盖已验证结果；
- 每日任务、长期追求和周期汇报可以在同一任务体系中持续跟踪。

## 指挥中心

指挥中心是 LumiCore 的持续工作空间，不是单独的演示页面。

- 文字对话与语音状态共享同一会话上下文；
- 新建对话、历史会话和任务账本分别管理；
- 指挥中心以 LumiCore 圆球与任务轨道显示实时工作状态；
- 正在执行的任务以独立组件呈现，不与聊天记录混为一谈；
- 支持每日固定任务、长期追求、周期汇报与单核连续执行；
- 个人模式、组织模式和指挥中心共享统一的执行入口。

## 模型与语音

### 模型编排

LumiCore 支持以下模型来源，具体可用模型由用户账号、服务端接口和本地运行时决定：

| 类型 | 支持方式 |
| --- | --- |
| DeepSeek、OpenAI、Anthropic、Gemini | 用户配置对应 API Key |
| Qwen / DashScope、豆包 / Ark | 用户配置对应平台凭证 |
| Kimi、GLM、小米 MiLM | 用户配置对应平台凭证 |
| Ollama、LM Studio | 自动检测本地服务，不经过客户端套餐限制 |
| 自定义 Relay | 连接 OpenAI 兼容接口 |

模型选择不会被底层静默替换。连接失败、模型不支持当前输入或降级条件不成立时，Lumi 应明确报告原因。不同模型的工具调用、视觉、长上下文和中文能力并不相同，能够连接不等于能够完成所有任务。

### 语音交互

- 语音唤醒、实时字幕、连续对话和打断；
- Qwen / DashScope、豆包语音和本地语音运行时；
- GPT-SoVITS、CosyVoice 与供应商 TTS；
- 供应商切换后只显示对应音色和克隆能力；
- 主界面与指挥中心共享语音开启状态；
- 本地 TTS 与声纹侧车按需启动，并受并发、内存和空闲回收策略约束。

语音能力需要单独的服务开通与凭证配置。LLM API Key、语音识别、语音合成和声音克隆可能属于不同产品权限。

## 记忆、知识与人格

- 会话、项目、偏好、关系和任务上下文分层保存；
- 文档进入知识库后进行解析、索引和检索；
- 记忆可以巩固、衰减、合并并保留来源；
- 人格配置和成长记录属于用户自己的本地数据；
- 用户可以询问 Lumi 当前身份、能力、限制和使用方法；
- 知识库“已索引”不代表模型已经永久掌握全部内容，回答仍应保留引用与检索过程。

## 技能、工具与外部协作

LumiCore 把行业能力放在技能层，把具体执行放在工具和适配器层，避免把业务全部写成不可解释的快捷脚本。

- 内置技能覆盖办公、法律、财税、电商、设计、数据、内容、采购、制造等方向；
- 工具覆盖桌面、文件、Office、网页、消息、知识库、媒体、CAD 和系统操作；
- MCP 用于连接外部软件、硬件、服务和专业能力；
- 支持与外部 AI 会话绑定、协作、结果归档和工作接管；
- 飞书、企业微信和微信机器人按账号与会话标识隔离路由；
- 外发、提交、改价、上下架等操作保留最终人工确认。

- [运行时能力统计](./docs/generated/capability-stats.md)

## 行业定制版

公开主仓库维护 LumiCore 的统一底层。行业版本从稳定主线派生，保留共同 Git 历史，并在各自仓库中进行表层适配和业务交付。

| 版本 | 主要工作区 |
| --- | --- |
| 电商版 | 今日经营、爆款雷达、店铺数据、商品管理、内容与客服 |
| 设计师版 | 设计项目、CAD 方案、效果图、提案 PPT、交付中心 |
| 律师版 | 案件工作台、文书生成、合同审查、法条与类案、财产线索、交付核验、标书制作 |
| 财税版 | 经营看板、票税管理、账务处理、税务申报、资金与风险、报表交付 |

这些版本不是四套重新开发的底层。它们共享模型、记忆、语音、意图、工具、回执和任务系统，再围绕特定用户压缩入口、词汇和工作流。通用改进可以通过独立提交反哺主程序。

## 从源码运行

### 环境要求

- Node.js `>=18`，推荐使用 Node.js 24；
- npm；
- Git；
- Rust stable 与平台构建依赖，仅桌面客户端需要。

### 获取源码

```bash
git clone https://github.com/5pyj29s7cm-tech/LumiCore.git
cd LumiCore
npm ci
```

复制环境配置：

```powershell
# Windows PowerShell
Copy-Item .env.example .env
```

```bash
# macOS / Linux
cp .env.example .env
```

在 `.env` 中配置至少一个可用模型服务，或者先启动 Ollama / LM Studio。不要把真实 API Key 提交到 Git。

### 启动

```bash
# 启动完整桌面开发模式
npm run tauri:dev

# 只启动本地服务与开发入口
npm run dev
```

### 构建

```bash
npm run build:desktop
npm run tauri:build
```

构建成功不等于安装包通过发布门禁。公开发行要求见 [COMMERCIAL_RELEASE.md](./COMMERCIAL_RELEASE.md)。

## 配置说明

完整配置见 [.env.example](./.env.example)。常见配置包括：

```env
# 至少配置一个云端模型，或使用本地 Ollama / LM Studio
DEEPSEEK_API_KEY=
OPENAI_API_KEY=
ANTHROPIC_API_KEY=
GEMINI_API_KEY=
DASHSCOPE_API_KEY=

# 豆包语音使用独立的单 API Key
DOUBAO_SPEECH_KEY=
```

桌面本地安装在未显式填写时会生成并保存设备本地认证值。组织服务器部署应自行设置强随机 `JWT_SECRET`，并配置明确的网络、CORS 与权限边界。

## 数据与隐私

默认用户数据目录为 `~/LumiCore/`，与源码仓库分离。升级时会在独占数据租约下将旧版 `~/LumiOS/` 原地迁移，不复制会话或凭据。

| 路径 | 内容 |
| --- | --- |
| `~/LumiCore/data/lumi.db` | 会话、记忆、任务、回执与 LumiCore 数据 |
| `~/LumiCore/data/keys.json` | 本地凭证存储 |
| `~/LumiCore/data/knowledge/` | 知识库文件与索引 |
| `~/LumiCore/data/voice_samples/` | 用户授权保存的语音样本 |
| `~/lumi_skills/` | 用户安装的 MCP 技能包 |

提交 Issue 或 Pull Request 时，不要上传 API Key、访问令牌、客户资料、个人数据库、语音样本或可识别真实账号的配置。发现安全问题请先阅读 [安全策略](./SECURITY.md)。

## 产品愿景

每个人都应该拥有一个真正属于自己的 AI。

它的记忆、人格和知识由用户掌控；它可以使用不同模型、连接不同载体，并在真实工作中持续形成可追溯的结果。LumiCore 是这个愿景的软件核心，未来将连接个人电脑、智能硬件、行业程序、外部 AI 和分布式算力节点。

行业定制不是偏离主线，而是让通用智能进入真实业务、接受稳定性交付检验，再把可复用能力反哺到底层。
