# 电商、财税独立版本合并到 LumiCore

日期：2026-09-23。

## 产品入口

主程序桌面新增「经营工作台」，包含电商运营、财务管理、任务与归档。

- 电商：今日经营、店铺数据、趋势研究、商品管理、内容与客服；保留报表导入、字段映射、库存/广告/售后/评论分析。
- 财务：经营看板、票税管理、账务核对、申报准备、资金与风险、报表交付；保留精确金额计算、来源复核和 Excel 生成、回读校验。
- 每个店铺、企业独立绑定，店铺可以关联企业。已有任务保存创建时的主体，不随当前选择改变。
- 配置和调用使用主程序已有模型设置、文字/语音执行管线、工具注册表、任务账本及完成回执；没有引入独立聊天模式或业务专属模型客户端。

## 合并时修正的问题

1. 浏览器提交的电商汇总不能充当原始事实：服务端按原始表格和字段映射重新计算。
2. 删除客服草稿中固定的演示退货规则和原因，改用当前输入。
3. 新业务工具纳入文字、语音的工具选择以及结果校验，避免仍只认可旧 MCP 工具名称。
4. “不写日常记忆、不改真实店铺”只约束这些操作，不能把本地经营分析及其回执一并禁掉。泛化的“禁止保存、禁止写入”仍生效。
5. 每个实际工具执行后保存回执，取消或模型超时不能抹掉已完成步骤。
6. 不提供毛利率时，投放工具的利润保持未知，取消隐含 35% 毛利假设。
7. 旧文件由 LumiOS-* 改为 LumiCore-* 后，按受限目录映射找回文件；拒绝网络路径、越界文件和源码清单。

## 数据迁移

旧版个人数据导入当前账户独立历史归档，不直接灌入当前账目或人格记忆。保留原状态作历史参考，不恢复执行旧任务；不复制账户密码、API 密钥。文件复制后记录 SHA-256，并通过当前账户的归档端点预览、下载。

本机迁移结果：电商 60 项任务、30 个对话；财税 29 项任务、22 个对话、5 份 Excel，缺失业务文件 0。旧数据库及仓库历史保留。

## 维护与发布

电商、财税版退出主程序的独立版本同步/发布清单，显式要求单独同步会报已合并。两个独立仓库增加合并说明及生命周期标记，安装包和 CI 的作业停用配置已修改。律师版和设计师版不在此轮范围。

这些是本地代码变更；GitHub 作业停用只有在相应提交进入远端默认分支后生效，不等同于远端已经停用。

## 验收范围

覆盖主体/账户/组织隔离、来源绑定、真实 Excel 生成及回读、取消回执保留、历史导入及鉴权、前端页签和文件预览入口、主程序文字/语音路由、任务最终回复、独立版本发布阻断。

真实官方 API 经营分析及财务交付使用隔离测试任务。失败记录和修复后实测结果保存到本机审计报告目录 `D:/LumiCore-Audit-Reports/20260923/business-consolidation`。

不把本地报告或草稿等同于真实店铺操作、税务申报、付款、消息发送。上述对外动作仍取决于已连接平台、账户权限和实际回执。本轮没有操作真实店铺、银行或税局。
## 本轮验收结果

- 24 个测试文件、541 项相关自动测试通过；lint、类型检查、前后端构建通过。
- 官方 API（主程序当前模型设置）真实经营分析：45.0 秒，1 个工具调用，完成状态 `delivered`。销售额 36000、订单 120、客单价 300、广告 ROAS 5、退款金额占比 10%；成本缺失时没有计算利润。
- 财务交付：实际生成 10644 字节 Excel，并完成内容回读、SHA-256 留证、任务归档。
- 5 份迁移 Excel 均可通过已登录账户预览；未登录访问均返回 401。
- 前端组件测试覆盖入口切换和归档文件预览。没有把后台接口测试说成实际鼠标点击客户端验收。
- 45 秒的官方模型首轮等待仍不理想；已消除业务完成后的额外模型总结等待，不保证所有官方请求都能在该时间内返回。
