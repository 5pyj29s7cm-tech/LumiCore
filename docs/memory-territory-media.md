# 记忆领地：照片、视频和真人形象

进入一个数字人的「人物资料 → 照片与录音」，选择或拖入素材。创建新人物后也能继续添加。素材按账号和人物私有保存，上传本身不会调用云端模型。

- 图片：JPEG、PNG、WebP，最多 20 MiB。
- 视频：MP4、MOV、WebM，最多 200 MiB、10 分钟。
- 录音：WAV、MP3、FLAC、OGG、M4A、WebM，最多 30 MiB、30 分钟。
- 音视频的本地处理需要运行环境能找到 `ffmpeg` 和 `ffprobe`；图片不需要它们。

「整理为记忆」是另一个操作：图片使用视觉模型，录音转成文字，视频使用封面和音轨转写。它不会理解视频中的每一帧。整理结果加入这个人物的独立资料，不加入公共知识库；结果可查看、移除，失败可重试。模型可能误读素材，应检查提取出的文字。

照片或视频可以「设为人物形象」。视频取一帧作为说话人像，不会复刻原视频的全身动作。上传和整理成功不代表已训练出声音或真人模型。

## 真人视频对话

在「人物资料 → 形象与声音 → 真人视频服务」保存自己的 D-ID API 密钥。密钥由后台按用户加密保存，不写入人物资料或发回浏览器。此功能使用 D-ID 服务额度，现有聊天 API 配置不会自动提供这项能力。

回到对话页面，勾选真人形象对话的授权说明，再开始通话。当前选定的人像和主程序生成的回复音频会发给 D-ID；回答、人物记忆和声音仍由主程序提供。视频对话还会开启自己的摄像头，将当前画面作为临时对话上下文。文字对话和不勾选真人形象的语音对话不需要 D-ID。

人像视频通过 WebRTC 播放。连接会等待服务真正报告就绪；打断会关闭旧视频并建立替代连接，挂断或切换人物会停止旧连接。服务不可用时显示失败并保留已保存的文字回复，不自动重复提交可能计费的请求。严格隐私模式禁止这项云端渲染。

本地通话上限为 5 分钟，需要时重新开始。删除云端资源未获确认时，后台保留清理记录，服务设置会提示到 D-ID 账号核对；本地已停止播放不等于所有远端素材已确认删除。

开发回归使用合成素材和受控服务响应。实际真人效果、延迟及账户权限需要配置真实服务后验证；自动测试不证明真人复刻质量。声音复刻沿用主程序已有能力，此入口可以选择已配置的声音，不会自动从新上传的视频或录音克隆音色。
