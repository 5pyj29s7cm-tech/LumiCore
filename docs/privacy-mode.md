# 严格模式

入口：设置 → 隐私与安全 → 严格模式。默认关闭。

开关保存后，必须完全退出并重新启动主程序才生效。界面分别显示保存的开关状态和当前实际运行状态；显示“待重启”时，正在运行的后台仍使用原来的模式。普通刷新网页不会重启后台。

开启并重启后：

- 内置云端 AI 请求被阻止，包括官网 API、用户临时提供 API Key 的对话、图像/视频生成、云端检索模型、云端生物验证和语音服务。
- 可使用已就绪的本地对话模型；本地模型服务地址必须在运行后台的这台电脑上，不接受局域网或远程地址，也不跟随 HTTP 重定向。
- 本地语音仅使用已有服务、运行环境和缓存模型。严格模式不会为 Whisper 安装依赖或下载模型，也不会为语音请求自动启动 GPT-SoVITS 服务。本地能力不可用时直接提示，不回退到云端。
- 所有自动工具执行暂停，包括本地文件工具、脚本、浏览器自动化和 MCP。任意工具及其子进程的联网行为无法仅凭工具说明保证，因此本版本采用统一停用规则。手动上传的本地解析和受控的本地模型处理仍可使用。

这是 Lumi 内置 AI 处理与自动工具的限制，不是操作系统防火墙，也不保证整个应用离线。账号服务、独立联网连接、用户打开的网页及其他程序的网络活动不在此开关的完整隔离范围内。远程客户端所说的“本地”是后台所在电脑，不是客户端所在设备。

设置会影响连接同一后台的所有客户端，因此仅允许本机个人工作区的管理员修改。组织成员、普通用户、子程序凭据以及经过代理转发的请求不能修改。登录用户可以查看当前状态。

设置保存在运行数据目录的 `privacy.json`，采用临时文件写入、同步落盘后替换。保存失败不会报告成功，损坏或无法读取的配置不会自动降为普通模式。部署者可设置 `LUMI_PRIVACY=strict` 强制启用，此时前端开关锁定；解除该环境限制后仍需检查已保存的设置。

关闭并重新启动后恢复已有模型配置；开关不会更改官网 API Key、模型选择或子程序设置。
