# 聊天唱歌工作台试用版（2026-09-16）

入口：主程序个人空间的对话右侧 → AI 创作 → 聊天唱歌。图片与视频合并成一个入口，内部按“图片／视频／聊天唱歌”分类；聊天唱歌不再独立放在关闭按钮旁。没有增加桌面图标或第二个执行器。

切换创作分类保留当前输入、对白草稿和所在步骤；关闭 AI 创作前保存已编辑的项目与卡点，保存失败时回到项目显示错误并保留输入。工作台只在首次进入聊天唱歌时加载。

## 本版范围

- 每一期作为独立项目保存，按账户隔离，跨聊天可重开；支持复用人物与风格设定开新一期。
- 设定、对白编辑、官方 API 草稿审阅、对白定稿。
- 图片与可选反应视频通过现有媒体任务执行和入库。创作任务携带 `officialOnly` 限制：模型设置不是 Lumi 官方时拒绝，不能悄悄走其他服务商。草稿调用同样固定官方线路，关闭跨服务商备用。
- 从跨对话素材库选用背景、头像、反应图和视频，也可上传到现有文件库。每期最多 12 个画面文件，图片 12 MB、音视频 80 MB；素材包画面合计上限 200 MB。
- 原文纯唱词、演唱要求、正式歌曲导入及试听核词。选歌时用现有 ffprobe 实测音轨与时长，不能信任前端自报时长。本机具备 ffprobe；其他安装环境需同样具备此工具。
- 用户按实际歌曲标记逐句起止时间，3:4 预览按已保存时间逐句揭示，同组累积，下一组替换。
- 主流程为“对白脚本 → 歌曲生成并确认 → 视频与配图 → 合成导出”。去掉每期的歌曲风格输入，复用演唱要求；视频生成在前后端检查歌曲已确认，图片可以提前准备。
- Lumi 在本机直接合成 1080×1440、25 fps、H.264/AAC MP4；按已保存卡点叠加横条、切换分组、展示反应图与对应视频片段，视频原声不混入歌曲。短片段末帧延长到对应句结束。
- 成片校验画幅、音轨、时长后存入跨对话视频库，工作台提供播放与下载，并保留上次成片回执。相同项目版本可复用成片；旧版本显示过期提示。素材替换、合成中修改项目、取消或处理失败不会登记为新成片。
- 合成使用私有临时目录与固定参数调用已有 ffmpeg，输入快照校验哈希、仅本地文件协议；单曲最长 5 分钟、视觉素材合计 200 MB、输出 256 MB，单账户同时一项、全局最多两项；退出时清理本次临时文件。
- 导出 ZIP：对白、纯唱词、演唱要求、确定性中文头像气泡横条 PNG、已选画面、已确认歌曲、剪辑 CSV、说明及项目 JSON。ZIP 与横条会登记到现有文件/图片库。
- 第 2 步的“让 Lumi 制作歌曲”交给既有 `sendText` 任务链试运行；第 4 步默认由 Lumi 本地合成。剪映与素材包收在“可选精修”中，仍需歌曲确认及完整卡点才可交接。任务交接成功不等于歌曲或成片已完成。

## 依赖与失效规则

对白定稿 → 汽水音乐生成歌曲、试听核词 → Lumi 官方 API 生成视频画面 → 保存实际卡点 → Lumi 合成导出。背景、头像和表情图片可提前准备，剪映用于可选精修。

修改对白、角色或歌曲风格会撤销对白定稿、歌曲确认、旧卡点；修改标题不影响已确认歌曲。换歌清除卡点。更改某句的反应画面建议后，相关素材要重新选择。文件内容被替换时，导出会校验 SHA-256 并拒绝使用旧引用。并发保存通过版本号防止互相覆盖。

保存失败时保留界面中的修改并显示错误，不假装保存成功。未完成歌曲确认与卡点时允许导出准备包，说明文件明确其状态，不填写猜测时间。
