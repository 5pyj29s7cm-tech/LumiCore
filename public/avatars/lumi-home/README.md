# Lumi home assets

The larger room architecture, terrain, curtains and scene behavior are implemented in `src/components/LumiHomeScene.tsx`. `src/components/LumiNightSkyline.tsx` adds locally modeled towers, lit windows, stars and a half-lit moon outside the window.

The wood, floor and linen PBR textures, sofa and potted plant are free public-domain assets from [Poly Haven](https://polyhaven.com), distributed under [CC0](https://polyhaven.com/license). They are bundled locally; the running application makes no Poly Haven API requests. See `SOURCES.json` for individual asset pages, original download URLs and checksums.

The foreground character remains the existing Lumi 2.5D portrait. This scene does not require a cloud avatar service or modify archived memory people.
